# Implementation Plan: "Avoid-3" — Reverse Tic-Tac-Toe on a 4×4 Board

## Background

The classic 3×3 Tic-Tac-Toe minimax (`tictactoe_minimax.py`) is used as the starting point.
The new game **inverts** all winning conditions on a larger 4×4 board.

| Aspect | Classic TTT | Avoid-3 (New Game) |
|---|---|---|
| Board | 3×3 (9 cells) | **4×4 (16 cells)** |
| Win condition | 3 tiles in a row | Most **unmatched** tiles when board fills |
| Instant-loss condition | None | **You** form 3 consecutive tiles → instant loss |
| Draw | Board full, no winner | Tied unmatched tile count at end |

### Terminal State Detection

#### [NEW] `has_instant_loss(board, player)`

```python
def has_instant_loss(board, player):
    """Return True if 'player' has formed any 3-consecutive line → instant loss."""
    for a, b, c in LOSS_LINES:
        if board[a] == board[b] == board[c] == player:
            return True
    return False
```

#### [NEW] `count_unmatched(board, player)`

```python
def count_unmatched(board, player):
    """Count tiles owned by 'player' not in any 3-consecutive line."""
    matched = set()
    for a, b, c in LOSS_LINES:
        if board[a] == board[b] == board[c] == player:
            matched.update([a, b, c])
    return sum(1 for i, v in enumerate(board) if v == player and i not in matched)
```

#### [NEW] `count_near_loss_lines(board, player)` *(heuristic helper)*

```python
def count_near_loss_lines(board, player):
    """Count lines with exactly 2 of 'player' and 1 empty — one move from instant loss."""
    count = 0
    for a, b, c in LOSS_LINES:
        cells = [board[a], board[b], board[c]]
        if cells.count(player) == 2 and cells.count(" ") == 1:
            count += 1
    return count
```

#### `check_winner()` → Rewrite as `check_terminal(board, last_player)`

```python
def check_terminal(board, last_player):
    """
    Returns:
      'X_LOSS' / 'O_LOSS'  — instant loss for that player
      'X_WIN'  / 'O_WIN'   — board full, more unmatched tiles
      'Draw'               — board full, equal unmatched tiles
      None                 — game still in progress
    """
    if has_instant_loss(board, last_player):
        return f"{last_player}_LOSS"

    if not get_available_moves(board):
        x = count_unmatched(board, "X")
        o = count_unmatched(board, "O")
        if x > o: return "X_WIN"
        if o > x: return "O_WIN"
        return "Draw"

    return None
```

> [!IMPORTANT]
> The `last_player` parameter is required because instant-loss detection only applies to the player **who just moved**. The opponent's prior sequences would have been caught in an earlier call.

### Minimax (Significant Rewrite)

#### [NEW] `heuristic_score(board)` — depth-limit evaluation

```python
def heuristic_score(board):
    ai_unmatched    = count_unmatched(board, "O")
    human_unmatched = count_unmatched(board, "X")
    ai_danger       = count_near_loss_lines(board, "O")
    human_danger    = count_near_loss_lines(board, "X")
    # AI wants opponent in danger and itself safe
    return (ai_unmatched - human_unmatched) + (human_danger - ai_danger) * 0.5
```

#### `minimax()` — Updated scoring, signature, and depth limit

New score table:

| Terminal Result | Score (from AI perspective) |
|---|---|
| `O_LOSS` | `-(INSTANT_LOSS_SCORE - depth)` |
| `X_LOSS` | `+(INSTANT_LOSS_SCORE - depth)` |
| `O_WIN`  | `+(BOARD_FULL_SCORE - depth)` |
| `X_WIN`  | `-(BOARD_FULL_SCORE - depth)` |
| `Draw`   | `0` |

Signature change:
```diff
-def minimax(board, depth, is_maximizing, alpha, beta):
+def minimax(board, depth, is_maximizing, last_player, alpha, beta):
```

Recursive calls pass `"O"` or `"X"` as `last_player` after each hypothetical placement.

When `depth >= MAX_DEPTH`: return `heuristic_score(board)` instead of recursing.
