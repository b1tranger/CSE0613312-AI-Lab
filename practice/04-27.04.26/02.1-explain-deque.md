### 1. `collections.deque`
*   **What it is:** A "Double-Ended Queue". 
*   **Why use it:** In BFS, you frequently need to remove items from the **front** of the queue (`popleft()`). 
    *   Using a standard Python **list** for a queue is slow ($O(n)$) because removing the first element requires shifting all other elements.
    *   Using **deque** is very fast ($O(1)$) for adding or removing items from both ends.

### 2. `([node])`
*   **Initial Data:** The `deque` constructor takes an iterable (like a list) to start with. 
*   **Starting Point:** By passing `[node]`, you are putting your starting vertex into the queue so the `while queue:` loop has something to begin with.
