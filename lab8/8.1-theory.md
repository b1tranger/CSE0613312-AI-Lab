# Informed Search: Best First Search

## Overview
Informed search strategies (also known as heuristic search) use domain-specific knowledge to find solutions more efficiently than uninformed search algorithms (like BFS or DFS). The algorithm is "informed" by a heuristic function, often denoted as *h(n)*, which estimates the cost of the cheapest path from the node *n* to the goal node.

## Best First Search (Greedy Best First Search)
Best First Search uses an evaluation function *f(n) = h(n)*. It expands the node that is estimated to be closest to the goal, according to the heuristic function.

### Key Characteristics:
- **Heuristic Function:** It relies entirely on the heuristic value *h(n)* to guide the search.
- **Priority Queue:** It uses a priority queue to keep track of the frontier, sorting nodes by their heuristic value in ascending order.
- **Completeness and Optimality:** Greedy Best First Search is *not* guaranteed to find the optimal (shortest) path, and it can get stuck in loops if not careful (making it incomplete in graphs with cycles unless visited nodes are tracked). However, it is usually much faster than uninformed search strategies.

### Comparison to A* Search
While Best First Search only looks at the estimated cost to the goal (*h(n)*), the A* Search algorithm considers both the cost to reach the node so far (*g(n)*) and the estimated cost to the goal (*h(n)*). Thus, A* uses *f(n) = g(n) + h(n)*, guaranteeing optimality.
